# 計畫：雙 ADC I/Q 前端（Si5351 + Tayloe QSD）

> 狀態：**計畫中**（2026-10-10）。本文件是 DESIGN.md §9「未來：Tayloe 子板」的具體化，
> 腳位安排跟 §9 原本寫的不同（見 §1）。

## 0. 目標

| | 現在（直接取樣） | 升級後（I/Q） |
| :--- | :--- | :--- |
| 收訊範圍 | 0–250 kHz（只有 LF） | 約 10 kHz–30 MHz（LF、MW、SW） |
| ADC | GPIO 26 單路實數，500 ksps | GPIO 26 = I、GPIO 27 = Q，各 250 ksps |
| 可視頻寬 | 0–250 kHz | 中心 ±125 kHz（複數，沒有鏡像） |
| 本振 | 無（NCO 全在數位端） | Si5351 出 4f → 74HC74 ÷4 → 四相 |
| 新佔用的腳 | — | GPIO 0／1（I2C0），原本就閒置 |

非目標：發射、FM 廣播、跟其他 8 個生態系韌體保持鍵盤接線相容（見 §7）。

## 1. 腳位

| GPIO | 現在 | 升級後 |
| :--- | :--- | :--- |
| 0 | 閒置（測試音 PWM） | **I2C0 SDA** → Si5351 |

| 27 | 165 QH（推挽，不能當 ADC） | **ADC1 = Q**（割斷原走線） |
| 其他 | | 不變（D-pad、SD、LCD、喇叭） |

## 2. 硬體

### 2.1 鍵盤：QH 與 SER 共用 GPIO 15

```
                 1 kΩ
74HC165 QH ────/\/\/───┬──── GPIO 15
74HC595 SER ───────────┘
GPIO 27 ── ✂ ── 原本的 QH 走線
```

- 寫 595：GPIO 15 當輸出，RP2040 蓋過 1 kΩ 後面的 QH（最多 3.3 mA，壓降 < 0.15 V）
- 讀 165：GPIO 15 切成輸入，QH 經 1 kΩ 推過來（RC 約 10 ns，掃描半週期 2 µs）
- 副作用：讀 165 的 8 個 CLOCK 會把 QH 推進 595 的移位暫存器。595 的輸出只在 LATCH
  上升時更新，而每次上升前都已經寫滿 8 bit，所以垃圾不會出現在列線上（見 §3.1 的驗證項）

### 2.2 Si5351 模組

- 常見的 Adafruit 相容模組（25 MHz 石英、3.3 V、板上已有 I2C 上拉）
- CLK0：4 × f<sub>LO</sub> → 74HC74 ÷4
- CLK2：**測試訊號**，取代 GPIO 0 的 PWM 測試音，用一圈線耦合進天線
- CLK1：保留
- 石英誤差約 ±20 ppm（7 MHz 時約 ±140 Hz）→ 要能校正（§4.5）

### 2.3 QSD 子板

```
天線 → 前級濾波 → FST3253（或 74HC4052）→ 4 顆取樣電容 → 雙運放差動 → I、Q
                       ↑ S0/S1
              74HC74 ÷4 ← Si5351 CLK0（4f）
```

| 項目 | 選擇 | 理由 |
| :--- | :--- | :--- |
| 開關 | FST3253（首選）／74HC4052 | 3253 導通電阻約 4 Ω，30 MHz 沒問題；4052 只到幾 MHz |
| 運放 | MCP6022 等 3.3 V 軌對軌 | 輸出要能停在 0.41 V 附近（見下） |
| 前級 | 先接 30 MHz 低通，之後再加分頻段帶通 | 方波本振的 3f、5f 也會混下來 |

**I 通道的偏壓限制（最重要）**：GPIO 26 在掃描期間要推鍵盤 CLOCK，取樣期間不能讓
74HC 誤判，所以：

- 運放輸出經 **串聯電阻（約 4.7 kΩ）+ 隔直電容** 接到 GPIO 26，原本的 330k／47k 偏壓網路保留，
  偏壓仍是 0.41 V；GPIO 推 CLOCK 時不會跟運放打架
- I 的擺幅要壓在 ±0.35 V 以內，不然會碰到 74HC 的 V<sub>IL</sub>（約 1.0 V）
- Q（GPIO 27）沒有這個限制，但**兩路偏壓與增益做成一樣**，I/Q 才平衡；不平衡的部分靠 §4.4 校正

## 3. 驗證步驟（每一階段可以單獨上機）

### 階段 P0：PC 模擬（不動硬體）
在 `test_pc.c` 造一段 I/Q 測試訊號（兩個載波，一個在 +f、一個在 −f），模擬：
- RP2040 ADC 輪流取樣造成的 **I/Q 時間差 2 µs**
- 增益差 1 dB、相位差 3°

量測：不校正、做分數延遲、做完整 I/Q 校正時，**鏡像抑制各是多少 dB**。目標 > 40 dB。

### 階段 P1：鍵盤 QH 共用
- 韌體：`KBD_SHARED_DATA` 編譯開關。開了 → `DATA_IN_PIN` = 15，`shiftOutSlow` 前設成輸出、
  `shiftInSlow` 前切成輸入；沒開 → 跟現在一樣
- 硬體：加 1 kΩ、割 GPIO 27 走線、飛線
- **驗收**：64 鍵全部按一遍（含 Shift 組合）、連打不漏鍵、鍵盤 LED 不閃、SDR 頻譜跟改之前一樣

### 階段 P2：Si5351
- 韌體：I2C0（GPIO 0／1，400 kHz）、Si5351 驅動（PLL、MultiSynth、R 分頻；PLL 固定、
  只改 MultiSynth，切頻時不會斷）。不用外部函式庫，大約 200 行
- 先只接模組：CLK2 輸出 68.5 kHz → 現在的直接取樣模式應該看得到，**取代** GPIO 0 測試音
- **驗收**：stats 頁顯示 Si5351 有回應；CLK2 設 50／100／200 kHz，頻譜上的位置都對

### 階段 P3：QSD 子板
- 先做 MW（530–1700 kHz），前級只用低通
- 先**只接 I** 到 GPIO 26，用現有韌體（單路實數）收 MW 電台，確認混頻器和偏壓沒問題、鍵盤還正常
- 再接 Q 到 GPIO 27

### 階段 P4：雙 ADC 韌體
見 §4。**驗收**：MW 電台在頻譜上只出現一次（沒有鏡像），AM 可以聽

### 階段 P5：UI 與頻段
- 頻率輸入擴展到 30 MHz（數字鍵輸入已經有）
- 頻段預設：LF（授時碼）、MW、49 m、41 m、31 m、25 m、19 m
- 預設清單（SD 卡）要能存 MHz 等級的頻率

### 階段 P6：校正
- I/Q 自動校正（§4.4）
- Si5351 頻率校正：收 BPC 68.5 kHz 或已知的 AM 台，量載波偏移，ppm 存到 SD 卡

## 4. 韌體修改

### 4.1 ADC 取樣
- `adc_set_round_robin(0b011)`：ADC0、ADC1 交錯取樣，總速率維持 500 ksps（clk_adc ÷96 不變），
  DMA 不用改，緩衝區裡就是 I,Q,I,Q…
- 每塊 32768 點 = 16384 對 I/Q，時間長度一樣是 65.5 ms，**記憶體不增加**
- 鍵盤分時不變：只有 GPIO 26 要切換；GPIO 27 一直是 ADC
- **round-robin 的起點**：每塊重新開始取樣時，第一點一定要是 ADC0，否則 I/Q 對調。
  啟動前要先 `adc_select_input(0)`，再確認 FIFO 已經清空

### 4.2 DDC（`ddc.c`）
- 輸入改成複數：NCO 混頻從「實數 × e<sup>−jωt</sup>」（2 次乘法）變成「複數 × 複數」（4 次乘法）。
  但速率從 500 k 降到 250 k，**總乘法數一樣**
- CIC 第一級 ÷8 → **÷4**（250 k → 62.5 k），第二級不變，輸出仍是 15625 Hz；後面的 FIR、解調、AGC、
  授時碼解碼都不用改
- `DDC_FS` 改成可設定（直接取樣 500000、I/Q 250000），讓兩種前端共用同一套程式
- 調諧：`tune_hz` 改成「相對於本振的偏移」（−125 k ～ +125 k）；絕對頻率 = f<sub>LO</sub> + 偏移
- **偏移調諧**：本振不要剛好放在目標頻率，設在目標 −30 kHz，避開 DC 附近的 1/f 雜訊與本振洩漏
- 本振只在調諧點離開可用範圍（±100 kHz）時才換，換的時候 NCO 補償，聽起來不會跳

### 4.3 寬頻 FFT（`fft.c`、`spectrum.c`）
- 實數 4096 點 → **複數 2048 點**（現在的實數 FFT 內部本來就是 2048 點複數再拆分，拆分步驟拿掉即可）
- 頻譜軸：f<sub>LO</sub> − 125 k ～ f<sub>LO</sub> + 125 k，DC 在正中央
- 中央那根 DC／本振洩漏線：畫面上遮掉或內插

### 4.4 I/Q 校正（Core 1）
1. **時間差**：Q 用短 FIR（8 階）延遲半個取樣週期，補 2 µs
2. **增益與相位**：常見的盲校正（I、Q 的功率比，加上 I·Q 的相關性），每塊更新一次，結果存成兩個係數
3. 放在 NCO 混頻之前，250 kHz 下跑。P0 量出來如果第 1 步就夠，第 2 步可以只在開機時算

### 4.5 Si5351 驅動（新檔 `si5351.c`）
- 純 C，不知道板子存在；I2C 讀寫靠函式指標注入（照 `ddc_clock_us` 的模式），`test_pc` 能驗證暫存器計算
- PLLA 固定約 800 MHz；CLK0 = 4 f<sub>LO</sub>，由 MultiSynth 小數分頻；f<sub>LO</sub> 低於約 500 kHz 時加 R 分頻
- ppm 校正係數

## 5. 資源預算（要在 P0／P4 確認）

| 項目 | 現在 | 估計變化 |
| :--- | :--- | :--- |
| RAM | 242.6 KB（剩 19.5 KB） | Si5351 驅動與校正 < 1 KB；ADC 緩衝不變 |
| Core 1 | 每塊 48 ms／65.5 ms | NCO + CIC 第一級總量不變；**I/Q 校正約 +3～6 ms** |
| Core 0 | 每塊 63 ms／65.5 ms | 複數 FFT 少了拆分步驟，應該略省；**餘裕只有 2.5 ms，是最大風險** |

## 6. 風險

| 風險 | 影響 | 對策 |
| :--- | :--- | :--- |
| QH 共用時序不穩 | 鍵盤漏鍵／誤觸 | P1 單獨驗收；不行就退回「SELECT 搬到 GPIO 1、Q 用 GPIO 28」，代價是 GPIO 1 不能接 I2C，Si5351 就沒地方接 |
| I 通道擺幅碰到 74HC 門檻 | 鍵盤 IC 亂移位，數位雜訊灌回訊號 | 運放增益保守；強訊號時前級加衰減 |
| 方波本振諧波 | 3f、5f 的電台混進來 | 前級低通／帶通 |
| I/Q 輪流取樣 | 鏡像抑制不足 | §4.4；P0 先量 |
| Si5351 輻射進天線 | 自我干擾 | 模組與天線分開，用屏蔽線 |
| Core 0 超時 | 掉塊 | §5 |

## 7. 對生態系的影響

改完之後主板的鍵盤接線跟其他 8 個韌體不同（它們從 GPIO 27 讀 QH）。這台改成 **SDR 專用機**。
如果之後想讓其他韌體也能跑，要在各 repo 加上同一個 `KBD_SHARED_DATA` 開關。這不在本計畫的範圍內。
